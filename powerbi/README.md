# Power BI Analytics Layer: Retail Demand & Inventory Optimization

This directory provides the analytical architecture, data model, and DAX measures for the 3-page Power BI executive dashboard described in the project architecture.

The exported CSV files generated by `src/pipeline.py` are saved in `data/processed/powerbi/`.

## 2. Core DAX Measures

Add these DAX calculations in Power BI to ensure mathematically robust aggregations:

### 1. Total Volume
```dax
Total Actual Units = SUM(Fact_Forecast_vs_Actual[actual_sales])
Total Forecast Units = SUM(Fact_Forecast_vs_Actual[forecast_sales])
```

### 2. Weighted Absolute Percentage Error (WAPE)
> *Why WAPE instead of MAPE?* Because individual item sales contain many zeros where MAPE divides by zero and explodes. WAPE sums absolute errors across the entire selected slice and divides by total actual sales.

```dax
WAPE = 
VAR AbsoluteError = 
    SUMX(
        Fact_Forecast_vs_Actual, 
        ABS(Fact_Forecast_vs_Actual[actual_sales] - Fact_Forecast_vs_Actual[forecast_sales])
    )
VAR Actuals = [Total Actual Units]
RETURN
    DIVIDE(AbsoluteError, Actuals, 0)
```

### 3. Signed Forecast Bias
> *Why Bias?* A positive bias indicates persistent over-forecasting (causes excessive working capital and spoilage). A negative bias indicates under-forecasting (causes stockouts and lost revenue).

```dax
Forecast Bias % = 
VAR NetError = 
    SUMX(
        Fact_Forecast_vs_Actual, 
        Fact_Forecast_vs_Actual[forecast_sales] - Fact_Forecast_vs_Actual[actual_sales]
    )
VAR Actuals = [Total Actual Units]
RETURN
    DIVIDE(NetError, Actuals, 0)
```

### 4. Inventory Order Spend
```dax
Total Recommended Spend = 
SUMX(
    Fact_Inventory_Recommendation, 
    Fact_Inventory_Recommendation[recommended_order_qty] * Fact_Inventory_Recommendation[unit_price]
)
```

### 5. High-Risk Item Count
```dax
Urgent Reorder Items = 
CALCULATE(
    COUNTROWS(Fact_Inventory_Recommendation),
    Fact_Inventory_Recommendation[stockout_risk] = "High"
)
```

## 3. The 3 Dashboard Report Pages

### Page 1: Forecast Tracking (Planner View)
- **Purpose**: Allows planners to inspect model accuracy over time and build trust.
- **Visuals**:
  - **Slicers**: Store ID, Category (`FOODS`, `HOUSEHOLD`, `HOBBIES`), Department, Item ID.
  - **Time Series Line Chart**: Date on X-axis, `Total Actual Units` (Black line) vs `Total Forecast Units` (Teal line).
  - **KPI Cards**: Overall WAPE, Forecast Bias %, 28-Day Cumulative Demand.

### Page 2: Segment Error Breakdown (Data Science & Category Managers)
- **Purpose**: Identifies where the model excels and where uncertainty is concentrated.
- **Visuals**:
  - **Matrix**: Category & Department in rows; columns showing WAPE, Bias, and Volume.
  - **Scatter Plot**: Intermittency (% Zero Days) vs RMSSE by Item to evaluate sparse demand handling.
  - **Bar Chart**: Forecast Bias by Category (shows whether perishable Food items are tilted towards over/under forecasting).

### Page 3: Inventory Replenishment & Decision Layer (Supply Chain Operations)
- **Purpose**: Translates forecasts into concrete purchasing actions and working capital allocation.
- **Visuals**:
  - **Executive KPI Cards**: Total Reorder Spend ($), Urgent Stockout Risk Items, Simulated Cost Reduction (%).
  - **Action Table**:
    - Columns: `item_id`, `Current Inventory`, `Reorder Point (ROP)`, `Recommended Order Qty`, `Unit Price`, `Stockout Risk Indicator`.
    - Conditional Formatting: Red highlight when `Current Inventory < ROP`.
